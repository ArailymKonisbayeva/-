# «Әдеби саяхат» — полный аудит проекта

Дата проверки: 18 сентября 2026 года  
Метод: **VERIFY → RECORD → CORRECT → VALIDATE → REPORT**

## A. Design changes

Создан единый финальный слой `design-system.css`, подключаемый после прежних тем. Он централизует:

- тёплые фоновые и поверхностные цвета;
- смысловые sage / blue / beige / cream акценты;
- типографику Manrope + Onest;
- радиусы, границы, тени и focus states;
- кнопки, карточки, формы, диалоги и состояния;
- desktop, tablet и mobile breakpoints.

Основные токены:

- `--background-main`, `--background-warm`;
- `--surface-primary`, `--surface-secondary`, `--surface-beige`, `--surface-sage`, `--surface-blue`, `--surface-cream`;
- `--text-primary`, `--text-secondary`, `--text-muted`;
- `--accent-primary`, `--accent-green`, `--accent-blue`, `--accent-warm`, `--accent-gold`;
- `--border-soft`, `--shadow-sm`, `--shadow-md`;
- `--radius-sm`, `--radius-md`, `--radius-lg`.

Обновлены Home, карта, библиотека, карточки произведений, страница произведения, игры, AI, профиль, достижения, поиск, auth UI, dialogs, empty states и responsive navigation. Разделы используют одну систему, но сохраняют характер: карта — sage/geographic; произведения — editorial cream; игры — warm interactive; AI — pale blue; достижения — beige/gold; профиль — neutral sage.

## F. Themes / ideas

Темы и main idea визуально отделены от фактов. Используется формулировка «шығармада ... көрініс табады / деп пайымдауға болады», без приписывания автору неподтверждённого намерения.

## G. Games

Старое раскрытие игры внизу страницы больше не используется. Маршруты:

- `#games` — общий выбор произведения;
- `#games/{workId}` — Game Center выбранного произведения;
- `#games/{workId}/{gameId}` — отдельная игровая сессия.

Реализованы механики:

| Игра | Произведение | Механика | learningObjective |
|---|---|---|---|
| Оқиғаларды ретте | Көксерек | ordering с кнопками вверх/вниз | понять порядок и причинно-следственные связи |
| Кейіпкерді тап | Көксерек | character clues | различать роли и поступки |
| Байланысты тап | Көксерек | matching | связать героя с проверенным действием |
| Дұрыс па, қате ме? | Көксерек | true/false + explanation | точно различать факты сюжета |
| Серігін таны | Ер Төстік | matching | различать роли спутников |
| Кім туралы? | Жусан иісі | character clues | различать роли персонажей |
| Кейіпкерлер байланысы | Ақбілек | matching | закрепить реальные отношения |
| Жырдағы байланысты тап | Қозы–Баян | matching | закрепить core-связи эпоса |
| Отбасылық байланысты тап | Ұлпан | matching | понять семейную линию |
| Отбасын таны | Балалық шаққа саяхат | matching | различать автобиографических персонажей |

Каждая сессия показывает инструкцию, difficulty, learning objective, прогресс, объяснение и result screen. Результат содержит повтор, выбор другой игры и возврат к произведению. Для произведений без безопасного игрового банка отображается empty state.

## H. AI assistant

Причина одинаковых ответов: первоначальный `sendChat()` возвращал один hardcoded абзац о «Көксерек», а поздний assistant читал импортированный `UNVERIFIED` объект и понимал только три intent.

Теперь помощник:

- определяет явно названное произведение, затем использует выбранный контекст;
- понимает author, genre, characters, plot, themes, relationships и vocabulary;
- читает тот же `VERIFIED_LITERARY_DATA`, что страницы и игры;
- добавляет источник;
- маркирует fact и interpretation;
- честно сообщает о недостатке данных;
- экранирует пользовательский ввод перед выводом.

## I. Profile / achievements

- Убраны фиктивные 120 стартовых XP и hardcoded streak «7 күн» из нового интерфейса.
- Завершённые произведения хранятся как уникальные IDs; повторный клик не увеличивает число.
- Игровые результаты хранят workId, gameId, score, total, percent, date и learningObjective.
- Посещённые регионы считаются уникально.
- Новое состояние учебного прогресса (завершённые произведения, игры, посещённые регионы и журнал действий) изолируется по email локального пользователя.
- Профиль показывает только реальные действия, результаты, посещённые регионы и сохранённые работы.
- Достижения вычисляются из действий, а не из фиктивных counters.
